# Amanda Lee Caskie Website

This is the personal website for Amanda Lee Caskie, built with Nuxt 3 and DatoCMS.

## Setup

Make sure to install the dependencies:

```bash
# npm
npm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# npm
npm run dev
```

## Production

Build the application for production:

```bash
# npm
npm run build
```

Locally preview production build:

```bash
# npm
npm run preview
```

## Deployment

This site is configured to be deployed on Netlify. The `netlify.toml` file contains the necessary configuration.

## Environment Variables

The following environment variables are required:

- `DATO_API_KEY`: The DatoCMS API key for accessing content

## Content Management

Content is managed through DatoCMS. The site uses the following content models:

- HomePage: Main page content
- SocialMedia: Social media links
- Class: Yoga class information

## Technologies Used

- [Nuxt 3](https://nuxt.com/)
- [DatoCMS](https://www.datocms.com/)
- [TailwindCSS](https://tailwindcss.com/)
- [Luxon](https://moment.github.io/luxon/)
- [Marked](https://marked.js.org/)
